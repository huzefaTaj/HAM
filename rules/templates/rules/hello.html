Rules

Contribution

  • Every member contributes {{ CURRENCY_SYMBOL }}{{ monthly_due|floatformat:0 }} per month, up to {{ CURRENCY_SYMBOL }}{{ annual_due|floatformat:0 }} per year.
  • You can never deposit more than what's left of your {{ CURRENCY_SYMBOL }}{{ annual_due|floatformat:0 }} annual limit for the year.
  • The limit resets automatically every January.

Fine

{% if FINE_ALLOWED %}
  • Missing a month's contribution adds a {{ CURRENCY_SYMBOL }}{{ monthly_fine|floatformat:0 }} fine for that month.
  • Paying a lump sum in advance covers that many months ahead. For example, paying {{ CURRENCY_SYMBOL }}1000 covers 2 months, and paying the full {{ CURRENCY_SYMBOL }}{{ annual_due|floatformat:0 }} upfront covers the whole year.
{% else %}
  • Fine is not being taken for the year 2026.
  • Fine will start again from January 2027.
{% endif %}

Expense & Income

  • An expense is split evenly across every active member's balance, except anyone specifically excluded.
  • Income or interest is split evenly and credited to every active member's balance, except anyone specifically excluded.

Fixed Deposit (FD)

  • An FD amount is split evenly across all active members except those excluded, and that share is locked from each person's balance. You can't use money that's locked in an active FD.
  • If any member doesn't have enough available balance for their share, the FD isn't created at all.

Approvals

  • A payment you submit yourself (contribution{% if FINE_ALLOWED %} or fine{% endif %}) doesn't take effect immediately. It stays pending until an accountant or super admin approves it.
  • Creating or completing an FD, and adding an expense or income, can only be done by an accountant or super admin.
